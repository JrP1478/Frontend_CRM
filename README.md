# Frontend.CRM

> **Repositorio anonimizado para portafolio.** Los nombres de empresa, clientes, logos, servidores y datos específicos del entorno original fueron sustituidos por valores genéricos.

Frontend de una plataforma CRM desarrollado con React, TypeScript y Vite.

## Stack

- React
- TypeScript
- Vite
- React Router
- ESLint
- Tests automatizados

## Configuración local

Copie `.env.example` y configure únicamente valores de su propio entorno. Los archivos de entorno reales no forman parte del repositorio.

```bash
npm ci
npm run dev
```

## Validación

```bash
npm run typecheck
npm run test
npm run build
```

Los nombres de clientes, marcas y configuración de infraestructura utilizados en el proyecto original han sido anonimizados.
